## Install the setup skill

Run this in your application directory:

```sh
edgestore agent setup --client codex
```

Use `claude` for Claude Code or `cursor` for Cursor. This installs the setup skill and configures MCP for the project. Add `--skills-only` to skip MCP, or `--global` to install for all projects. Restart your client or open a new task to load the skill.

The skill uses the API references bundled with your installed EdgeStore packages. To install the skill bundled with a newer CLI release, run:

```sh
edgestore agent update --client codex
```

Updating the skill leaves your application packages unchanged.

## Connect MCP

To configure MCP without the skill:

```sh
edgestore mcp setup --client codex
```

For manual configuration, add this remote HTTP server:

```text
https://api.edgestore.dev/mcp
```

Sign in through your client and choose which permissions to grant. This endpoint connects to production accounts.

Use MCP for supported remote actions. The [EdgeStore CLI](https://github.com/edgestorejs/edgestore/tree/next/packages/cli#readme) handles local project linking and credential delivery.

## Give your agent the docs

Use [next.edgestore.dev](https://next.edgestore.dev/docs/quick-start) for v1 prereleases and [edgestore.dev](https://edgestore.dev/docs/quick-start) for 0.2.

- [llms.txt](/llms.txt) lists the docs.
- [llms-full.txt](/llms-full.txt) includes all pages in one Markdown response.
- Add `.md` to a page URL, such as [quick-start.md](/docs/quick-start.md), or use its Copy Markdown button.

Run `edgestore agent context --json` to find installed versions and their local `agent-docs/` references.

Adapter guides cover [Next.js](/docs/adapters/next), [Hono](/docs/adapters/hono), and [TanStack Start](/docs/adapters/tanstack-start).
