`file-list.tsx` exports:

- `FileList`: lists the files of the nearest `UploaderProvider`.
- `FileListItem`: renders one file with its status, progress and actions (retry, cancel, remove).
- `FileBadge`: renders the colored file-type tile.

Use it next to an [Upload Button](./upload-button), or anywhere you want the files of an `UploaderProvider` shown as a list.

<Callout>
  The [multi-file](./multi-file) and [file field](./file-field) components
  install it automatically via the CLI.
</Callout>

## Usage

```tsx
<UploaderProvider uploadFn={uploadFn} autoUpload>
  {/* anything that adds files, e.g. <UploadButton /> */}
  <FileList />
</UploaderProvider>
```

## Props

| Prop       | Type      | Default | Description                                 |
| ---------- | --------- | ------- | ------------------------------------------- |
| `disabled` | `boolean` | `false` | Hides the retry, cancel and remove actions. |
| `...`      |           |         | Any other `<ul>` prop, such as `className`. |
