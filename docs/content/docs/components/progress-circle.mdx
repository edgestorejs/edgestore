## Usage

Import the component and provide the `progress` prop. You can optionally customize the `size`, `strokeWidth` and whether the percentage is shown.

```tsx
import { ProgressCircle } from '@/components/upload/progress-circle';

function ProgressDemo() {
  return (
    <div className="flex items-center gap-4 rounded-lg bg-black/80 p-4 text-white">
      {/* Default size */}
      <ProgressCircle progress={75} />

      {/* Larger size with thicker stroke */}
      <ProgressCircle progress={75} size={64} strokeWidth={6} />

      {/* Smaller size without the percentage */}
      <ProgressCircle progress={75} size={24} strokeWidth={3} showValue={false} />
    </div>
  );
}
```
