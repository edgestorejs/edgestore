---
title: Remix / React Router
description: Add EdgeStore uploads to Remix or React Router framework applications.
---

Use the Remix adapter with Remix or React Router framework mode. A client-only
React Router application needs a separate backend; this route runs on the server.

## Setup

### Install

```package-install
@edgestore/server @edgestore/react
```

### Environment variables

Copy your project's keys from the [dashboard](https://dashboard.edgestore.dev) to the backend env file:

```sh title=".env"
EDGE_STORE_ACCESS_KEY=your-access-key
EDGE_STORE_SECRET_KEY=your-secret-key
```

<Callout type="warning">
  Add `.env` to `.gitignore`.
</Callout>

### Backend

Create the EdgeStore API route:

```ts title="app/routes/api/edgestore.ts"
import { initEdgeStore } from '@edgestore/server';
import { createEdgeStoreRemixHandler } from '@edgestore/server/adapters/remix';

const es = initEdgeStore.create();

const router = es.router({
  publicFiles: es.fileBucket(),
});

export type EdgeStoreRouter = typeof router;

const handler = createEdgeStoreRemixHandler({
  router,
});

export { handler as loader, handler as action };
```

For React Router framework mode, add the endpoint to your existing routes file:

```ts title="app/routes.ts"
import { index, route, type RouteConfig } from '@react-router/dev/routes';

export default [
  index('routes/home.tsx'),
  // [!code ++]
  route('api/edgestore/*', 'routes/api/edgestore.ts'),
] satisfies RouteConfig;
```

For Remix v2's default file-based routing, put the same handler in
`app/routes/api.edgestore.$.ts` instead. For custom routing, see
[Remix route conventions](https://v2.remix.run/docs/file-conventions/routes/)
and [React Router routing](https://reactrouter.com/start/framework/routing).

### Frontend

Create the React provider:

```tsx title="app/lib/edgestore.ts"
import { createEdgeStoreProvider } from '@edgestore/react';
import type { EdgeStoreRouter } from '~/routes/api/edgestore';

const { EdgeStoreProvider, useEdgeStore } =
  createEdgeStoreProvider<EdgeStoreRouter>();

export { EdgeStoreProvider, useEdgeStore };
```

Point the type-only import at your actual route module; for the Remix filename
above, use `~/routes/api.edgestore.$`.

Wrap the root component with the provider:

```tsx title="app/root.tsx"
// [!code ++]
import { EdgeStoreProvider } from '~/lib/edgestore';

// ...

export default function App() {
  return (
    <EdgeStoreProvider>
      <Outlet />
    </EdgeStoreProvider>
  );
}
```
